# 归物本

一款面向真实生活场景的本地优先成本记录工具。它既能记录手机、电动车、家电等长期持有物品，也能管理房租、话费、健身、保养等周期费用，并把不同类型的支出统一换算成容易理解的日均或月均成本。

> 在线体验：[https://futaosmile.github.io/guiwuben/](https://futaosmile.github.io/guiwuben/)

## 为什么做归物本

普通记账工具擅长回答“今天花了多少钱”，归物本更关注“这笔投入摊到每一天究竟值多少”。它用时间把一次性购买和持续支出放到同一套成本视角中，帮助你了解长期使用成本，而不只是记录付款瞬间。

## 主要功能

- **两类记录模型**：区分长期物品和周期费用，表单字段会随场景变化。
- **真实成本计算**：长期物品从购买日计算到今天或报废日；周期费用按明确的起止日期摊销。
- **日/月视角切换**：首页可查看当前日均或月均成本。
- **成本趋势**：独立趋势页展示最近 30 天和最近 12 个月的综合成本变化。
- **Emoji 图标**：通过弹窗挑选 Emoji，不依赖图片上传也能快速识别记录。
- **分类与检索**：支持分类筛选、关键词搜索和多种排序方式。
- **详情与编辑**：查看单条记录的周期、累计投入、保修和备注信息。
- **备份与恢复**：数据可以导出并重新导入，方便迁移和保管。
- **本地优先**：数据存放在浏览器 IndexedDB 中，不需要注册账号或连接服务器。
- **响应式界面**：针对移动端设计，同时可在桌面浏览器使用。

## 成本如何计算

### 长期物品

适用于手机、电动车、电脑、家具等一次性购入并持续使用的物品。

```text
持有天数 = 购买日期至今天的自然日数（包含首尾日期）
日均成本 = 购入金额 ÷ 持有天数
```

如果设置了报废或结束日期，则用该日期代替今天，日均成本也会固定下来。

### 周期费用

适用于房租、话费、会员、年度保养等在指定周期内发生的费用。

```text
固定总额日均成本 = 周期总金额 ÷ 起止日期内的自然日数
月度费用日均成本 = 每月金额 × 12 ÷ 365
年度费用日均成本 = 每年金额 ÷ 365
周期预计支出 = 日均成本 × 起止日期内的自然日数（包含首尾日期）
```

界面支持三类费用：培训班、疗程、短租等选择“固定总额”，填写整个周期的总价以及必填的起止日期；房租、话费等月度费用和保养、年费会员等年度费用，则按输入的月费或年费固定折算。月度和年度费用的结束日期可选，留空代表持续发生，累计支出会自动计算到今天。

### 月均成本

```text
月均成本 = 日均成本 × 365 ÷ 12
```

金额以“分”为单位存储，展示时保留两位小数，以减少浮点计算误差。

## 技术栈

- Vue 3 + TypeScript
- Vite
- Pinia
- Vue Router（Hash 模式，兼容 GitHub Pages）
- Dexie + IndexedDB
- Zod
- Vitest + Happy DOM

## 本地运行

需要 Node.js 20 或更高版本，推荐使用当前 LTS 版本。

```bash
npm ci
npm run dev
```

开发服务器启动后，按照终端提示在浏览器中打开本地地址。

## 测试与构建

```bash
# 运行全部测试
npm test

# 类型检查并生成生产版本
npm run build

# 本地预览生产版本
npm run preview
```

生产文件会生成在 `dist/` 目录中。

```text
├─ components/    通用界面组件

├─ pages/         首页、表单、详情、趋势和设置页面
├─ router/        页面路由
├─ services/      导入、导出等应用服务
├─ stores/        Pinia 状态管理
├─ styles/        全局样式与设计变量
├─ tests/         领域规则和交互测试
├─ types/         TypeScript 数据模型
└─ utils/         通用工具
```

## 数据与隐私

归物本是纯前端应用，所有记录只保存在当前浏览器的 IndexedDB 中，不会上传到任何服务器。清除浏览器站点数据会删除本地记录，请定期在设置页导出备份。不同浏览器、设备或无痕窗口之间的数据不会自动同步。

## GitHub Pages 部署

仓库内置 GitHub Actions 工作流。推送到 `main` 分支后会自动执行测试、生产构建并部署到 GitHub Pages；也可以在仓库的 **Actions** 页面手动运行部署流程。

## 浏览器支持

建议使用最新版 Chrome、Edge、Firefox 或 Safari。应用依赖 IndexedDB；若浏览器禁用了站点存储，记录将无法持久保存。
